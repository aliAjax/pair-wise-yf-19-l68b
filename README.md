# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 柜位对调

在「柜位对调」工作台选择两件**已上柜**标本，登记各自目标柜位与**调换凭据**：

- **整批判定**：两个目标柜都为空、两件标本鉴定均为「已接受」、均未外借、未被其他待审对调占用——任一条件不满足则整批不通过，原柜位不变。
- **待审锁柜**：登记通过后两个目标柜位与两件标本立即锁住（柜位图标记「待审锁定」，不能上柜、不能再次参与对调），撤回对调单才释放。
- **复核生效**：审批时以当前数据重新判定（待审期间若发生外借/状态变更会被拦下并保持待审）；全部满足才一次性原子写入两件标本的新柜位。
- **同步展示**：生效后馆藏柜位记录、采集地点卡、标本详情中的柜位与流水同步更新。
- **历史保留**：生效与撤回记录全部保留，可在详情中追溯关联对调单号。
- **持久化**：全部数据存于 `localStorage`，浏览器刷新后仍在（页脚可重置演示数据）。

判定、流转、展示拆分到三个业务文件：

| 文件 | 职责 |
| --- | --- |
| `src/herbarium/swapRules.ts` | 纯判定：规则常量、柜位/标本占用与锁定查询、`checkSwap` 整批校验 |
| `src/herbarium/swapFlow.ts` | 纯流转：登记待审、复核整批生效、撤回释放，及入库/上柜等状态迁移 |
| `src/herbarium/SwapPanel.tsx` | 展示：登记表单、实时判定清单、待审卡片（生效/撤回）、调换历史 |

其他模块：`store.ts`（useSyncExternalStore + localStorage）、`seed.ts`（种子数据）、`CabinetBoard.tsx`（柜位图）、`LocationCards.tsx`（地点卡）、`SpecimenList.tsx`（队列与筛选）、`SpecimenDetail.tsx`（详情）。
